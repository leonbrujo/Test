# Pipeline editorial (piloto)
Sin API de IA. ChatGPT entrega editorial/inbox/YYYY-MM-DD.json. Python recopila RSS, valida fuentes y renderiza la edición. El workflow de esta rama es deliberadamente de prueba: no escribe en main ni despliega. Los RSS son candidatos aún no comprobados. La validación HTTP no demuestra veracidad ni licencia; el editor debe corroborar ambos. El JSON debe incluir date, cutoff_at (ISO con offset), verification=verified, title, summary, categories, sections (world, main, briefs, analysis, watch, washington, river), dictionary. Cada sección tiene id,title,articles; cada artículo id,title,paragraphs (array),sources (array HTTPS), opcional image (url,credit,license,source,caption). Cada entrada del diccionario kind,title,terms,text,priority.
